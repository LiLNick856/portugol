# portugol
Repositório de Portugol
Este repositório contém uma coleção de algoritmos desenvolvidos em Portugol, focados no aprendizado de lógica de programação e estruturas fundamentais.

Lista de codigos + explicaçao 

1. Verificador de Maioridade   Este programa solicita que o usuário informe a sua idade. Através de uma estrutura condicional, o sistema verifica se o valor inserido é inferior a 18 anos para classificar o usuário como "menor de idade" ou, caso contrário, como "maior de idade".

2.  Sistema de Notas Escolar   Um sistema simples para calcular a média aritmética entre duas notas fornecidas. O algoritmo define que, se a média final for igual ou superior a 6, o aluno é considerado aprovado; caso seja inferior, o sistema exibe o status de reprovado.

3.  Este código é mais avançado e utiliza funções e laços de repetição.  Ele permite processar múltiplos alunos de uma vez:  Entrada: Define a quantidade de alunos a serem cadastrados.   Processamento: Para cada aluno, chama uma função para ler as notas e calcular a média.   Validação: Utiliza uma função específica para verificar a aprovação com base na média obtida.

4.Armazenamento de Dados (Vetores)   
Este exemplo demonstra o uso de vetores (arrays) para armazenar informações de forma organizada na memória. O código ilustra como declarar e atribuir valores a posições específicas de uma lista, abrangendo tanto tipos de dados textuais (nomes) quanto numéricos (inteiros).

5.Gerador de Tabuada   
Um utilitário que automatiza o cálculo da tabuada. O usuário insere um número e o programa utiliza um laço de repetição (para) para calcular e exibir instantaneamente os resultados da multiplicação desse número de 1 a 10.
